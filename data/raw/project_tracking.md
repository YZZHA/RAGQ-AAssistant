# 外资项目跟踪管理系统功能说明

## 系统定位

外资项目跟踪管理系统（FDI Project Tracking System, FPTS）实现外资项目从签约意向到投产运营的全生命周期跟踪管理，覆盖项目储备、签约、审批、开工、投产五个阶段。

## 项目阶段定义

### 1. 储备阶段
- 有投资意向，尚未正式签约
- 跟踪指标：投资方背景、意向金额、意向地区
- 转化目标：转为签约项目

### 2. 签约阶段
- 双方正式签署投资协议
- 系统记录签约金额、签约日期、协议期限
- 签约项目自动生成唯一的项目跟踪编号（格式：PT-YYYY-XXXXX）

### 3. 审批阶段
- 项目进入政府审批流程
- 跟踪各审批节点状态，自动更新审批进度
- 关键节点预警：审批超时自动通知相关负责人

### 4. 开工阶段
- 获得施工许可后进入开工阶段
- 记录实际开工日期、计划竣工日期
- 支持月度投资完成额填报

### 5. 投产阶段
- 项目正式投产运营
- 记录实际投产日期、首年产值、就业人数
- 项目结束后自动归档

## 预警机制

- 签约后90天未进入审批阶段 → 黄色预警
- 审批阶段超期50% → 橙色预警
- 开工后进度滞后30%以上 → 红色预警

## 数据报表

系统支持自动生成以下报表：
1. 项目进度总览表（实时）
2. 季度投资完成情况分析
3. 年度招商引资绩效统计
4. 项目问题清单及处理进度

## 权限管理

- 普通用户：查看权限范围内项目信息
- 项目经理：管理所负责项目，更新进度
- 部门主管：查看管辖范围内所有项目
- 系统管理员：全部权限，包括配置管理
