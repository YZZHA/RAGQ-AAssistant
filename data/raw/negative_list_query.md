# 外商投资负面清单查询系统操作手册

## 系统简介

外商投资负面清单查询系统（Negative List Query System, NLQS）提供实时查询各行业、各地区外商投资准入限制的功能。系统与国家发改委、商务部发布的《外商投资准入特别管理措施（负面清单）》实时同步。

## 数据更新

- 负面清单数据与国家政策同步更新
- 每年至少更新一次，重大政策调整实时更新
- 数据版本号格式：YYYY-VN（如2024-V2表示2024年第二版）

## 查询方式

### 方式一：行业分类查询
- 按《国民经济行业分类》（GB/T 4754-2024）代码查询
- 支持行业大类（门类）、中类（大类）、小类三级查询
- 示例：查询"信息传输、软件和信息技术服务业"

### 方式二：关键词检索
- 输入关键词自动匹配
- 支持模糊搜索和精确搜索两种模式
- 示例：搜索"增值电信"、"教育"、"医疗机构"

### 方式三：地区+行业组合查询
- 选择省份 + 行业类别
- 自由试验区内外差异对比
- 显示该地区该行业的特殊限制政策

## 查询结果说明

| 结果类型 | 标识 | 说明 |
|----------|------|------|
| 鼓励类 | ✅ | 允许外商投资，享受优惠政策 |
| 限制类 | ⚠️ | 有条件开放，有股比/高管要求 |
| 禁止类 | ❌ | 不允许外商投资 |
| 暂未明确 | ❓ | 需咨询相关部门确认 |

## 2024年重点关注行业

1. 增值电信业务：外资股比不超过50%（基础电信禁止）
2. 医疗机构：限于合资
3. 教育机构：限于合作办学
4. 新闻出版：禁止
5. 广播电视：禁止

## 常见问题

**Q: 负面清单每年什么时间更新？**
A: 通常每年上半年发布新版，重大政策调整时实时更新。

**Q: 自由贸易试验区是否有特殊政策？**
A: 是的，自由贸易试验区通常适用更加开放的负面清单，限制类别少于全国版。
